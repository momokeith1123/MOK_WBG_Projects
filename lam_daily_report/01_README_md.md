# IFC Treasury — LAM Daily Confidential Report

## Overview

This project generates a daily confidential PDF report for IFC Treasury LAM Sub-Account Summary and distributes it automatically to senior management via email. It connects to the Financial Data Lake (FDL), processes portfolio P&L data, renders a formatted PDF, and sends it via SMTP.

## Prerequisites

- Python 3.9 or higher
- ODBC Driver 17 for SQL Server installed on the machine
- Access to FDL (`publishFINDATAREP`) with appropriate permissions
- Access to an IFC SMTP relay for email distribution

## Setup Instructions

### 1. Clone or download the project

```bash
cd /your/preferred/directory
```

### 2. Create a virtual environment

```bash
python -m venv venv
source venv/bin/activate        # Linux / Mac
venv\Scripts\activate           # Windows
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure settings

Copy `.env.example` to `config/settings.py` and fill in your real values:

```bash
cp .env.example config/settings.py
```

Open `config/settings.py` and update:
- `CONNECTION_STRING` — your FDL server and authentication method
- `SMTP_SERVER` — your IFC SMTP relay hostname
- `TO_EMAILS` — the management distribution list
- `FROM_EMAIL` — the sender address

### 5. Run the development notebook first

Open `notebooks/LAM_Daily_Report_DEV.ipynb` in Jupyter and run all cells top to bottom to validate data, layout, and email before going to production.

```bash
jupyter notebook notebooks/LAM_Daily_Report_DEV.ipynb
```

### 6. Run in production

```bash
python lam_daily_report.py
```

## Scheduling

### Windows Task Scheduler

1. Open Task Scheduler → Create Basic Task
2. Trigger: Daily at 07:00 AM (adjust to your business timezone)
3. Action: Start a program → `python`
4. Arguments: `C:\path\to\lam_daily_report.py`
5. Set working directory to the project root

### Linux / Mac (cron)

```bash
crontab -e
```

Add the following line to run Monday–Friday at 7:00 AM:

```
0 7 * * 1-5 /path/to/venv/bin/python /path/to/lam_daily_report.py >> /path/to/logs/cron.log 2>&1
```

## Key Design Decisions

| Decision | Rationale |
|---|---|
| `src/` modules | Each concern is isolated — easier to debug and maintain |
| `config/settings.py` in `.gitignore` | Credentials never reach version control |
| `TEST_MODE` flag in sender | Prevents accidental sends to management during testing |
| Relative row computed in `builder.py` | Not stored in DB; derived as Portfolio P&L − Benchmark P&L |
| Landscape A3 PDF | Matches the width of the management template |

## Troubleshooting

| Symptom | Likely cause | Fix |
|---|---|---|
| `pyodbc.Error` on connect | Wrong server name or driver | Check `CONNECTION_STRING` in `settings.py` |
| Empty DataFrame | No data for latest business date | Check FDL table directly in SSMS |
| `Deal_Type` mismatch | DB values differ from `"Benchmark"`/`"FTP"` | Update `DB_DEAL_TYPES` in `builder.py` |
| PDF not opening | ReportLab error | Check `logs/` for the full traceback |
| Email not delivered | Wrong SMTP relay or port | Confirm relay with IFC IT |
