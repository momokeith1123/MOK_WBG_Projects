## File: `.env.example`

Save this file at the project root as `.env.example`.
This is the **safe template** — it shows teammates what variables are needed without any real credentials.
Each developer copies this to `config/settings.py` and fills in their own values.

```
# ── Copy this file to config/settings.py and fill in your values ─────────────
# ── DO NOT commit config/settings.py to version control ──────────────────────

# Database
FDL_SERVER   = "<your_fdl_server>"
FDL_DATABASE = "publishFINDATAREP"
FDL_AUTH     = "ActiveDirectoryIntegrated"   # or "SqlPassword"
FDL_UID      = ""                            # leave blank if using SSO
FDL_PWD      = ""                            # leave blank if using SSO

# Email
SMTP_SERVER  = "<your_smtp_relay>"
SMTP_PORT    = 25
FROM_EMAIL   = "treasury-reports@ifc.org"
TO_EMAILS    = "recipient1@ifc.org,recipient2@ifc.org"
CC_EMAILS    = ""

# Output
OUTPUT_DIR   = "./output"
LOG_DIR      = "./logs"
```
